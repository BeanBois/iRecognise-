01 — About

Brain-Inspired Computing
for the Edge

Classical computing AI struggles at the constrained edge. This project investigates how the neuromorphic paradigm — sparse, event-driven, distributed — maps naturally onto decentralised federated learning.

Problem

Edge devices like cameras and sensors lack the compute needed for modern AI. The Von Neumann bottleneck, dense synchronous computation, and centralised federated architectures all compound this limitation.

Approach

Neuromorphic Computing encodes intelligence in temporal spike patterns across interconnected neurons, collocating memory and computation. This maps naturally to the sparse, asynchronous nature of edge workloads.

Task

Surveillance camera facial/mask recognition — a real-world constrained edge AI task — used to benchmark the neuromorphic model under simulated day, night, and rain conditions.

Contribution

A fully custom SNN inference pipeline with R-STDP learning and a decentralised federated protocol (Broadcaster / Listener / Updater) implemented in Python using Intel's Lava framework.

02 — Architecture

System Architecture

Four interacting entities form a fully decentralised federated learning system. Each edge node runs all four models concurrently.

Input
Image → Grayscale → Hilbert binning → Poisson spike encoding
→
SNN Core
10×200 excitatory + 2×400 inhibitory neurons, WTA competition
→
Federated
Broadcaster → Listener → Updater over HTTP. No central server.
🧠

Inference Model

SNN-based binary classifier. Excitatory and inhibitory modules in a Winner-Takes-All topology.

📡

Broadcaster

Monitors RSTDP synapse weight deltas. Broadcasts averaged updates every 100 steps with a device ID.

👂

Listener

Receives broadcasts, converts device ID to spikes, passes through Reservoir Computing to assess trust.

🔄

Updater

Reservoir-based decision module. Approves or rejects incoming weight updates based on accuracy delta.

03 — Methods

Learning Techniques

Standard backpropagation does not apply to SNNs. Three complementary learning strategies are employed.

01

Spike Timing Dependent Plasticity

Synaptic weights are strengthened when pre-synaptic neurons fire before post-synaptic ones (Δt > 0), and weakened otherwise. Implemented via Lava's LearningDense and STDPLoihi abstractions.

STDP
02

Reward-Modulated STDP

Extends classical STDP with a neuromodulatory reward signal M(t) ∈ {+1, −1}. For binary classification, the WTA setup naturally integrates rewards by toggling A+ and A− signs based on predicted vs actual labels.

R-STDP
03

Reservoir Computing

A fixed, randomly connected pool of 200 LIF neurons acts as dynamic memory for the Updater. The output layer trains a weighted sum to approve or reject weight updates from other devices with delayed reward signals.

RC

04 — Results

Findings & Evaluation

The experiment revealed key limitations of current neuromorphic software running on classical hardware — and pointed to promising directions.

Hardware Results

Lava's parallelism is implemented as threads — this causes severe performance degradation on Raspberry Pi 3B's limited multi-threading (1 GB RAM, OOM killed).

Even on an M1 MacBook Pro (16 GB), the model was computationally expensive and did not converge after 12+ hours of training.

Response rate of ~13–14 responses/minute achieved but fell below expectations for a constrained edge device.

R-STDP did not function as expected — WTA competition caused groups to inhibit each other during learning, producing noisy weight updates.

Evaluation & Outlook

Despite experimental limitations, the theoretical case for neuromorphic edge AI remains strong:

  • Researchers with dedicated neuromorphic hardware show energy efficiency gains over classical AI, with competitive accuracy on some tasks.
  • Commercial investment from IBM, Intel, BrainChip, and Innatera signals long-term viability.
  • Open-source platforms like Lava enable community growth and iterative improvement.
  • Neuromorphic properties — sparsity, asynchrony, in-memory compute — are architecturally well-suited to the federated edge scenario.

"Neuromorphic Computing is not yet ready to tackle complex tasks with limited computing resources — but it will get there."
